## 4. Theory

**1. Hyperlinks:**
`<a href="page.html">text</a>` creates a link. The `href` attribute holds the address of the target page.

**2. Images:**
`<img src="images/photo.jpg" alt="description" width="200" height="200">` shows a picture. `width` and `height` set its size.

**3. Alt Text:**
The `alt` attribute describes the picture. It is shown if the picture is missing and is read aloud by screen readers.
