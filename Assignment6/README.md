## 4. Theory

**1. Unordered List:**
`<ul>` with `<li>` items shows bullet points.

**2. Ordered List:**
`<ol>` with `<li>` items shows numbers. A list placed inside an `<li>` is a nested list.

**3. Description List:**
`<dl>` holds terms in `<dt>` and their descriptions in `<dd>`.
