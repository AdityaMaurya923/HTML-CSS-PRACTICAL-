## 4. Theory

**1. HTML Document Structure:**
Every page starts with `<!DOCTYPE html>` followed by the `<html>`, `<head>` and `<body>` elements. The `<title>` inside the head is shown on the browser tab.

**2. Headings and Paragraphs:**
`<h1>` to `<h6>` create headings (h1 is the largest). `<p>` creates a paragraph.

**3. Text Formatting:**

- `<strong>` : Important text (bold).
- `<em>` : Emphasised text (italic).
- `<br>` : Line break inside a paragraph.
