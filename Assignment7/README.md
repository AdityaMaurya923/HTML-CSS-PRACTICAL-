## 4. Theory

**1. Semantic Tags:**
`<header>`, `<nav>`, `<main>`, `<section>` and `<footer>` describe the meaning of each part of a page.

**2. Page Anchors:**
A link such as `<a href="#about">` jumps to the element with `id="about"` on the same page.

**3. Email Links:**
`<a href="mailto:name@example.com">` opens the email program of the user.
