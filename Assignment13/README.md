## 4. Theory

**1. Flexbox:**
`display: flex` makes the children of a container flex items placed in a row.

**2. Alignment:**
`justify-content` aligns items along the main (horizontal) axis and `align-items` along the cross (vertical) axis.

**3. Wrapping:**
`flex-wrap: wrap` moves items to a new row when there is not enough space.
